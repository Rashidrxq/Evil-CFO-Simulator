# Evil CFO Simulator — Frontend MVP

A dark, responsive React + TypeScript frontend prototype for an adversarial corporate-finance simulation game.

## Requirements
- Node.js 20 or newer recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Build
```bash
npm run build
npm run preview
```

## What's included
- Responsive dark dashboard UI
- Sidebar navigation across Dashboard, CFO Activity, Investigate, Risk Analysis, and Reports
- KPI cards and financial performance chart
- CFO decision banner and round progression
- Interactive evidence review states
- Prototype risk comparison table and report score
- Mock data only; no backend or AI integration yet

## Important
All company values and findings are fictional demo data. Financial calculations and game rules will be implemented in a separate simulation layer before connecting an AI opponent.
